# على الفحم — إدارة الصالة

نظام عربي متوافق مع الهاتف لإدارة عمال الصالة، والاستراحات، والتقييمات، والخصومات، والحضور، والتقارير اليومية والشهرية.

## التشغيل السريع

1. افتح `index.html` أو انشر المستودع باستخدام GitHub Pages.
2. سجّل الدخول محليًا بكلمة مرور المدير الافتراضية `1234` أو المشرف `2222`.
3. غيّر كلمات المرور الافتراضية من الإعدادات فورًا.
4. أضف العمال وحدد لكل عامل رقمًا سريًا.

**تنبيه:** عند التشغيل دون إعداد السحابة، تُحفظ البيانات في المتصفح/الجهاز الحالي فقط. مسح بيانات المتصفح أو استخدام جهاز آخر لا ينقل البيانات تلقائيًا. استخدم النسخة الاحتياطية من داخل النظام بانتظام.

## تفعيل المزامنة السحابية بين الأجهزة

المزامنة تستخدم Supabase. إعدادها مطلوب مرة واحدة للمشروع، ثم إدخال إعدادات الاتصال وتسجيل الدخول على كل جهاز:

1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor وشغّل محتويات الملف `SUPABASE_SETUP.sql`.
3. من إعدادات المشروع انسخ Project URL وPublishable key (أو anon key القديم)، وأدخلهما في إعدادات المزامنة داخل الموقع.
4. أنشئ حسابات تسجيل دخول في Supabase Authentication، ثم استخدم بريد وكلمة مرور حساب مصرح بهما على كل جهاز.
5. اختبر الاتصال والمزامنة المباشرة. تأكد من تفعيل Realtime لجدول `public.hall_state`.

لا تضع أبدًا `service_role` أو secret key داخل HTML أو المتصفح.

## تنبيه أمني مهم قبل الاستخدام الحقيقي

النسخة الحالية تخزن جميع بيانات العمال وسجلاتهم في صف واحد من جدول `hall_state`. وسياسات RLS في ملف SQL الحالي تسمح لأي مستخدم مسجّل في Supabase بقراءة وتعديل ذلك الصف. لذلك لا تعتبر حسابات Supabase الحالية فصلًا آمنًا بين صلاحيات المدير والمشرف والعامل. قبل استخدام بيانات حقيقية، يجب تطبيق صلاحيات موثوقة من جهة الخادم وربط كل دور بهوية موثّقة؛ كلمات المرور والأدوار المخزنة في JavaScript وحدها ليست حماية أمنية.

## الملفات

- `index.html`: تطبيق الويب.
- `SUPABASE_SETUP.sql`: إعداد جدول المزامنة وسياساته الحالية.
